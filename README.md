# herlife
A private, AI-powered wellness app designed exclusively for women to track, reflect, and manage their emotional and physical well-being securely and personally.

## Secure Architecture
This project implements an enterprise-grade, zero-trust security model. For detailed documentation on our defense-in-depth strategy, backend ownership controls, and database Row-Level Security (RLS), see **[SECURE_ARCHITECTURE.md](SECURE_ARCHITECTURE.md)**.

For developers, the **[BACKEND_SECURITY_GUIDE.md](BACKEND_SECURITY_GUIDE.md)** provides deep dives into specific attack preventions (SQLi, IDOR, Mass Assignment) and secure coding standards.
